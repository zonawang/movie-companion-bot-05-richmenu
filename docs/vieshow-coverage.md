## 名稱與查詢

- 可查城市：台北、新北、桃園、新竹、苗栗、台中、台南、高雄、花蓮；也可列出雙北或北／中／南／東部。
- 「威秀」清單包含 2 間 MUVIE；指定品牌「MUVIE」可只列出 MUVIE。
- 「新竹威秀」「台南威秀」「大遠百威秀」可能對應多館，先列候選讓使用者指定，不自動選第一間。
- 保留「老虎城威秀」「松仁威秀」「林口三井威秀」等別名。開眼仍使用「台中老虎城威秀」時，對應官方目前的「MUVIE CINEMAS 台中TIGER CITY」，避免將同一據點重複登錄。
- 分館清單可一次列全台；場次比較每次最多 3 館，請先指定分館，避免回覆過長。

## 驗證範圍

- 43 項離線回歸測試通過，新增全台清單、MUVIE 篩選、縣市隔離、別名碰撞及分館來源唯一性驗證。
- `npm run smoke:cinemas:all`：兩個 worker 逐館讀取，每館有自己的快取與來源網址；不呼叫 Gemini、不傳 LINE、不讀寫個人票根。
- `npm run smoke:cinemas:national:adk`：使用真實 Gemini／ADK 驗證全台清單、新竹分館歧義、高雄場次及東／中／南三館明日比較；會使用模型 API 額度。
- 今日資料可讀不代表未來永久可用。新開、停業、改名與來源格式變更需重新驗證；未公告或讀取失敗時如實回覆。
- 真實 Gemini／ADK 已跑通以上自然語言流程；LINE 現有服務已重啟載入全台名單，官方 webhook 測試回傳 200，票根完整保留。手機實際收到各館回覆，仍需使用者在 LINE 操作確認。
