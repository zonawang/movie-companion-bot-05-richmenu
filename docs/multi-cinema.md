# 多影城與分館場次

本版已擴充為 108 個影城／放映場館，102 個可解析場次、6 個為圖片入口，詳見 [全台覆蓋表](taiwan-coverage.md)。威秀／MUVIE 的官方目錄核對紀錄另見 [威秀覆蓋](vieshow-coverage.md)。品牌與分館是不同欄位；威秀不是一間分館。`list_cinemas` 只列出已支援據點，全台威秀範圍以核對日為準，不宣稱涵蓋之後的新開據點或其他品牌全台影城。

## 來源選擇與驗證

2026-10-26，搜尋／瀏覽工具能顯示威秀官方分館頁，但本機 `curl` 與標準 Node HTTPS client 均收到 403 Access Denied。未嘗試登入、cookie、代理繞過或驗證挑戰。能在瀏覽工具看到頁面，不代表部署後的程式有穩定直接存取能力。

目前改用可公開讀取的 [信義威秀開眼時刻表](https://www.atmovies.com.tw/showtime/t02a01/a02/) 與 [西門威秀開眼時刻表](https://www.atmovies.com.tw/showtime/t02b08/a02/)，回覆明確標示第三方來源。官方核對入口：[信義](https://www.vscinemas.com.tw/theater/detail.aspx?id=1)、[西門](https://www.vscinemas.com.tw/theater/detail.aspx?id=31)。誠品仍使用原本的官方來源。

這是本機開發的讀取能力驗證，不是取得資料供應合約或保證長期可用；要擴大規模應另評估穩定的資料合作方式。

## 工具與資料流程

- `list_cinemas({brand, city, page?})`：已登錄據點，附品牌、縣市與圖片入口標示。每頁 25 間，回傳 total、pageCount 與 hasMore，避免 LINE 直接截斷長清單。
- `cinema_schedule({cinema, date, afterTime, onlyUpcoming, movieTitle?})`：單一分館，支援別名及台／臺。
- `cinema_compare({cinemas, date, afterTime, onlyUpcoming, movieTitle})`：一次 2～3 間，各自取得結果，不因其中一館失敗而丟掉其他館。

ADK 理解使用者句子與挑選工具。分館 ID、來源 URL、日期與時間驗證、時間篩選和場次回覆由程式處理。保留所有同輪查詢結果，最多輸出三組；不再由最後一次單館呼叫覆蓋前一館。

## 解析與日期

開眼每個分館有自己的來源代碼與頁面。解析時核對 `h2` 分館名稱、時刻表前的完整 `YYYY/MM/DD` 日期及每個電影／版本區塊。不能只找到一串時間就當成正確場次。沒有版本標示時不推測為數位版。

查未來日期會讀取 `/YYYYMMDD/` 頁；若網站回傳的是另一天，回覆「尚未查到這天的場次資料」。HTTP 錯誤、格式變更或無法辨識的時間回覆「暫時無法讀取」，不改用模型猜測，也不以過期快取補上。凌晨仍保留來源日期，不推算下一日；遇到無法辨識的 24 點以上標示會拒絕解析，需另驗證來源語意後再支援。

指定片名採正規化後的文字包含比對，保留原片名與版本供核對，沒有做跨來源電影 ID 的自動配對。同名、續集、重映版仍可能同時出現。每個版本的時間獨立列出；沒有符合結果不代表售完或當日沒有放映。

## 快取與訊息長度

每個分館及日期使用不同快取 key，5 分鐘內共用。同一 key 同時查詢合併為一個請求；失敗後 30 秒降頻，過期快取不作為現在結果。每次請求 8 秒上限、2 MB 內容上限，不跟隨重新導向。來源 URL 只能取自登錄表，模型不能傳任意網址讓伺服器讀取。

多館回覆會保留各館名稱、日期、來源及官方入口，場次清單依訊息預算縮短並提示指定片名。不直接截斷整串訊息而遺失來源。單輪最多三間分館，超出需縮小範圍。

## 下次新增分館

1. 確認來源中的分館名稱、穩定 ID、日期入口及官方核對連結。
2. 在 `cinema-registry.mjs` 登錄，補別名；相同 provider 沿用解析器。
3. 用自製 HTML 測試分館隔離、版本、日期、跨年及失敗情況。
4. 真實讀取及模型選工具驗證通過，再標示支援。

新品牌不一定沿用相同 HTML 結構；需要新的 provider。新增名單不等於已完成場次串接。

## 跨品牌與縣市

資料以獨立來源代碼去重；誠品保留官方 provider，不與開眼的同一場館重複登錄。新竹市與新竹縣依來源地址區分，短稱新竹可涵蓋兩者。其他品牌與地方戲院資料在 `taiwan-cinemas.json`。清單能力標示是核對日快照，查詢仍依當下讀取結果回覆。

`parseAtmoviesSchedule` 在確認分館身分後，才辨識圖片時刻表；只接受來源網域的圖片路徑。圖片頁回傳 `links_only`，不從檔名月份或更新時間猜放映日期。來源頁提供的影城網站與已核對官方入口分別標示。
