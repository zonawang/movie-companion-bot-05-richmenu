# 電影夥伴 Bot 04 LIFF 使用條款

本專案為電影查詢與個人票根紀錄的學習工具。使用附近影院功能前請閱讀 [隱私說明](privacy.md)。

地點資料由 Google Maps 提供，使用時同時受 [Google 服務條款](https://policies.google.com/terms) 與 [Google Maps／Google Earth 額外服務條款](https://maps.google.com/help/terms_maps/) 約束。顯示地點名稱、地址及距離時會附 Google Maps 來源連結；第三方地圖資料提供者另行標示。

影院距離是依座標計算的直線估算，不是步行、開車時間或即時交通資訊。附近搜尋並不保證涵蓋所有影院；地圖分館與場次來源無法可靠對應時，僅提供查詢入口。

電影場次來自誠品官方公開時刻表或開眼電影網第三方來源，與 Google Maps 地點資料分開列示。電影、版本、日期、入場規則與售票資訊以影城為準。列出場次不保證仍有座位；本專案不代訂票或收費售票。

電影介紹與評論使用 TMDB，詳見 [資料來源聲明](credits.md)。專案與 Google、LINE、TMDB、開眼或各影城沒有合作或背書關係。

部署者應提供聯絡與資料刪除管道，並依實際部署情境調整服務條款、隱私政策、保存期限與服務可用性說明。API 用量及費用由自行設定金鑰的部署者承擔。

票匣紀錄為私人收藏；儲存前請確認片名與日期。刪除需經確認且無法由一般介面復原。請勿轉傳專屬入口連結。相同票根同時在多個頁面修改時，系統會要求重新載入最新資料，以避免覆蓋其他頁面的變更。
